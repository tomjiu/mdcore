# DOCX 可编辑化（#115）——Buffer ↔ DocxEditor 双向映射

> 任务：把 docx 从「只读渲染」接成「可编辑」——**不重写编辑器**，复用
> mang-shell 既有管线（Buffer → display_map → 渲染 → 光标 → 选区 → 命令），
> 只在「打开 / 编辑 / 保存」三处接一条**可逆的双向映射**。
> 引擎层（`crates/office-io/src/docx_edit.rs`——`DocxEditor` 外科手术式
> 编辑，13 面保真矩阵 + 18/18 真实语料）**一行未改**。

## 1. 结构（五个文件，一处未动引擎）

| 文件 | 角色 |
|------|------|
| `mang-shell/src/editor/docx_edit_bridge.rs`（新） | **桥**：`LineBlock` 行归属、`DocxPort` 引擎窄面、`DocxBridge`（可逆映射 + 回写计划 + 编辑门禁）、`DocxEditing`（Buffer 钩子实体） |
| `mang-shell/src/editor/docx_doc.rs`（改造） | **装载**：`load_editable`（宽面行模型 + 窄面引擎，段落序对账）；表格/文本框改只读；行切分改「引擎装配文本」口径 |
| `mang-shell/src/editor/mod.rs`（接入） | **编辑器**：`new_docx_editable`、`save`/`save_as` 走 docx 字节写盘、`after_edit` 幂等回写、批量手势收尾 |
| `mang-shell/src/editor/buffer.rs`（加钩子） | `EditHook`（变更前问、变更后报）+ `UndoHook`（撤销/重做同步行归属）——**唯一变更入口处接线**，其余编辑路径零改动 |
| `mang-shell/src/document.rs`（分派） | `EditableDocx` 分派 + 启动证据行（可编辑/降级 + 原因） |

## 2. 管线（打开 → 编辑 → 保存）

```text
打开   load_editable(path)
       ├─ 宽面 read_docx_from_bytes ──→ 行模型（纯文本行 + span + 标题树）
       ├─ 窄面 DocxEditor::open    ──→ 段落索引（w:p 文档序 + 拒改面标记）
       ├─ #156 sdt 盲区跳过（引擎 in_sdt 段：宽面结构性丢弃 → 空投影
       │  不入行流；sdt 包表格 → 整篇降级只读——栅格错位不可写）
       └─ 段落序对账（候选段 = 宽面 w:p 数 + sdt 盲区 = 引擎 w:p 数）
          → 对不上就降级只读

编辑   Buffer（rope）← 钩子挂在唯一变更入口 replace_range / replace_batch
       ├─ before_edit：起点/终点行是否锁定（表格/域/修订/文本框/清单）→ 拒
       └─ after_edit ：行归属重排（段内序号）→ 当场重算回写计划 → set 进
                       引擎待落账层（只对「文本真的变了」的段落 set）

保存   Ctrl+S → save_docx
       ├─ 再 sync 一次（撤销/重做走物理回放不过钩子，必须补一次）
       ├─ 逐段正文比对 → 只对变化段 set_paragraph_text
       ├─ DocxEditor::save_to_vec（引擎单趟拼接，非目标部件 raw_copy）
       └─ 临时文件 + rename 写盘（半截写入不毁原件）
```

## 3. 核心不变量（可逆性）

> **未编辑的段落必须回写「原文全等」，否则一律不调用 set。**

引擎的 `set_paragraph_text` 是**外科手术**不是「改文字」：即使新文与旧文逐字
相同，它也会合并多 run 段、给 `w:t` 加 `xml:space="preserve"`、把自闭合
`<w:p/>` 转成开形。所以桥侧先做逐字节比对——**没动就一次 set 都不发**。

三条硬性质（集成测试 `tests/docx_edit_roundtrip.rs` 钉定）：

1. 打开后不编辑 → 保存 → **非目标 zip 条目逐字节恒等 + 全段文本恒等**；
2. 编辑一段 → **只改这一段**：其余段文本不变、非 `document.xml` 条目
   逐字节不变（`raw_copy` 透传的直接证据）；
3. 改文字不坏格式：`styles.xml`/`numbering.xml`/`fontTable.xml` 逐字节
   不变、列表段 `w:numPr` 仍在、加粗 run 属性仍在。

## 4. 第一版支持面（实测）

| 面 | 状态 | 说明 |
|----|------|------|
| 正文段落（含多 run 富格式） | ✅ 可编辑 | 改文字保留首个含文本 run 的 `w:rPr`（引擎口径） |
| 标题段落 | ✅ 可编辑 | `w:pStyle` 不动（Heading 样式保留） |
| 列表段落（有序/无序/多级） | ✅ 可编辑 | 行模型的 `1. `/`• ` 是装饰：改正文回写不带标记；编号定义文本不动 |
| 软换行（`w:br`）段 | ✅ 可编辑 | 按引擎装配文本拆行（`\n` 可往返）；改任一行 → 软换行保留 |
| 缩进段（悬垂/首行缩进） | ✅ 可编辑 | 续行缩进拆成填充行（可往返）；正文比对同口径 |
| **表格** | ⛔ 只读 | 整表原文透传；行模型不伪造网格行，只出「表格：N 个（M 行；第一版只读）」清单行 |
| **文本框** | ⛔ 只读 | 同表格：内层段落不进编辑面（嵌套编辑互斥，引擎 L1） |
| **页眉 / 页脚 / 批注 / 脚注 / 尾注** | ⛔ 只读 | 不入正文流；出清单行说明；原文逐字节透传 |
| 域代码段 / TOC 段 | ⛔ 只读 | 引擎 typed 拒改（缓存值会与指令失配）——行模型标锁定并给原因 |
| 修订段（`w:ins`/`w:del`） | ⛔ 只读 | `RevisionPolicy::Refuse` 下引擎拒改 |
| `mc:Fallback` 副本段 | ⛔ 只读 | 双分支一致性防线 |
| 段落**增删** | ⚠️ 部分 | 段内回车/合并可用；**整段删除/新增段落**在保存时按原段落集合写回（无归属行计入 `无归属 K 行` 证据行）——登记 |

## 5. 编辑行为细则

- **锁定行**：光标可到、可选中、可复制，但任何变更（含 Backspace/Delete/
  IME/粘贴）在 Buffer 唯一入口处被拒，并在 stderr 留 `edit-guard: 拒绝编辑（原因）`。
- **撤销/重做**：Buffer 的 undo 栈照常（一条手势一条记录）；撤销是**物理回放**
  （`apply_core`），桥侧通过 `UndoHook` 同步行归属、`after_edit` 把当前
  文本重新落进引擎待落账层——语义上「撤销到底 = 回到原文」，保存时把原文写回。
- **查找替换**：复用 G1（`FindState::replace_current`/`replace_all`），整批
  派生编辑（一条 undo）；替换只落在可编辑段（锁定段的行不属于任何段落槽位）。
- **多光标 / 缩进**：复用现有管线；多行批手势收尾统一「行数保真」重映射。
- **节流**：本版**不做时间节流**——引擎落账发生在内存（`pending`），写盘只由
  Ctrl+S 触发；每次变更只重算「受影响的段落文本」（O(段落数) 字符串比较），
  没有每键写盘。

## 7. 已知边界与后续（显式登记，不假装支持）

1. **表格文字不可改**（第一版）。要支持需把单元格段落接进行模型并保留
   「网格投影 ↔ 单元格段落」的映射；当前先把「表格只读」做成看得见的清单行。
2. **段落增删**（整段删除 / 在文末新起段落）：保存按原段落集合写回，残行计入
   `无归属` 计数；引擎目前没有 insert/delete paragraph 接口（加性扩展即可）。
3. **撤销的字节面**：撤销到底会让段落文本回到原文，但引擎已经做过一次手术
   （多 run 合并、`xml:space` 规范化），因此**字节不等于原始文件**——语义
   （文本 + 格式属性）等价。要字节级还原需要「不落账」的会话级 pending 丢弃，
   属后续优化。
4. **降级面 33/129**：宽面块模型（docx-rs）与窄面 XML 扫描在「表格内嵌表 /
   文本框嵌套」等形态上段落数不一致——降级是安全侧，不误改；后续可用窄面
   自己的段落序做行模型来源，彻底消除对账分歧。
5. **文本框内段落**：引擎侧标 `in_textbox` 并拒改（L1 嵌套互斥），行模型
   同样只读。
6. **#156 sdt（结构化内容控件）盲区**：docx-rs 读模型把 `w:sdt` 解析为
   `StructuredDataTag`，宽面读门**结构性丢弃**其内容（登记的模型级切片
   面外项）——**纯段落 sdt**（标书导出链的 TOC、Word 目录内容控件）经
   引擎 `in_sdt` 旗标 + 装载门盲区跳过后**可编辑**（盲区段空投影、字节
   保真透传；docx4j 语料 +13 件转可编辑）；**sdt 包表格**仍整篇降级
   （块序↔栅格对位不可信，宁缺毋错）。
7. **#156 标书真档的域/批注面**：标书生成器（ai-bid-research → docx-rs）
   正文只产 TOC 域（跨段只读——typed 拒保护）且**不产批注**（comments.xml
   0 条）；页脚 PAGE/NUMPAGES 域在 footer 部件（引擎 v1 坐标系只扫
   document.xml）——四面貌编辑中域/批注两面在标书真档上无既有目标可改，
   属生成器现状（登记，非引擎缺陷；端到端证据 =
   `tests/docx_bid_e2e.rs` + `--smoke-docx-bid` 烟雾）。
