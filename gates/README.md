# 门禁台账（按 issue 拆分）

## 约定

```
一个 issue 一个文件：gates/<issue-number>.md
标题格式：# #NNN：<主题>（日期，来源/审计编号）
内容：背景 → 侦察实证 → 实现 → 测试证据 → CI
完成后在 gates.md 的索引表加一行
```

## 为什么拆分

```
旧做法：所有 issue 记录追加到 gates.md 末尾
问题：多 PR 并行时必然同点冲突（2026-11-06 单日 5 次：
      #235×1 / #241×1 / #242×1 / #243×2 / #246×3）
新做法：一个 issue 一个文件 → 永不冲突
```

## 新 issue 怎么写

```
1. 新建 gates/<issue-number>.md
2. 按上面的标题格式写内容
3. 在 gates.md 索引表加一行
4. PR 里只改这两个文件（你的新文件 + 索引的一行）
   ← 索引那一行仍可能冲突，但只有 1 行，好解
```

## 如果想彻底零冲突

```
索引也不手动维护，改成脚本生成：
  scripts/gen-gates-index.py 扫描 gates/*.md 生成索引表
本拆分（#248）先手动，后续需要再自动化。
```
