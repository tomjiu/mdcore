# #302：PDF 消费倒挂——桌面标注接线（阶段 2·④，2026-11-07，P0 / 研究仓 acrobat-mapping §10）

**背景**：mdc-pdf 12,325 LOC 引擎代码只有 ≈5 个符号被桌面产品触达
（读路径 pdfium 四符号 + generate 一函数）——写面全家（增量写/标注/
表单/组织/签名）零接线。「能力写了产品不用」= 维护成本高 + 用户拿
不到价值（打开 PDF 只能看不能批注）。本条 = 研究仓建议的最小消费
闭环：**桌面 PDF 标注**。

**本 PR = 阶段 2 剩余的 ④**（分支 `feat/302-pdf-annotate-wiring`，
基于 main `7178eba`）：

- **新模块 `mang-shell/src/pdf_annotate.rs`**（零 GPUI 依赖——纯
  Rust + mdc-pdf engine-lopdf 面，写路径全量可无 GUI 测试）：
  `PdfAnnotateController`：
  - `open`：安全门序 = S2/S6 `open_scan`（危险族评估）→ S5 加密
    写面拒 → S3-L7 `LopdfWriter` 输入门（xref 链守卫）→
    `PdfSession::open` + `attach_writer`；
  - lopdf 几何直读（页数 + 双盒 + `/Rotate`，含 `/Parent` 继承上溯
    + 环防御）→ `PageTransform::from_geometry`（#304 变换源——
    无引擎环境的权威几何）；
  - `add_highlight_from_screen`：屏幕拖框（任意对角序）→
    `screen_rect_to_quad`（#304：归一化 + 旋转 + Y 翻转 + DPI 四合一）
    → `AnnotateAdd` 命令面（六命令即产品接线面）；
  - `flush`（增量保存事务：产物 = 原字节前缀 + 追加修订）/ `save`
    （落盘 = 前缀保持覆写，非重写）/ `annotation_rev`（#305 渲染
    键控 rev 源）/ `list`（AnnotateList 观测）。
- **`pdf_pages.rs` 接线**（GPUI 交互层——编译面验证 + 真机登记）：
  - 缓存键迁 `RenderKey`（#305：`(页,宽)` + 引擎实测高 + rev——
    `rendered_heights` 记录引擎侧报告值，回执落地组装全键）；
  - **右键拖框 = 高亮**（右键不占列表滚动）：页槽叠加透明 canvas，
    paint 期注册窗口级右键按下/松开观察器（shell 面板拖拽收尾钩
    同模式：每帧重注册 + bounds 过滤 + 无命中区不挡滚动）；
  - `commit_highlight`：懒初始化控制器（首次批注才付 open_scan +
    写器门成本，纯阅读路径零负担）→ DPI 由「位图宽/显示域宽×72」
    推导 → flush → `reload_after_flush`；
  - `reload_after_flush`：换字节快照 + 重建渲染工人（引擎重开见
    追加修订）+ `invalidate_stale_revisions` 即刻回收（#305）+
    rev 镜像同步（下一帧重光栅即见高亮——issue 验收 5）；
  - 错误横幅（批注失败不静默丢——面板明示可重试）。

## tranche ② 增量（验收 1 三手势收口——2026-11-07，Agent-9716）

**范围**：issue 验收 1 原文「桌面能对 PDF 加批注（高亮/下划线/便签）
并保存」——tranche ① 只交付了高亮单手势（当时登记「多 kind 手势
属后续轮」）；本 tranche 补齐下划线 + 便签两手势，验收 1 收口。

**控制器面（`pdf_annotate.rs`）**：

- `AnnotateTool` 枚举（Highlight/Underline/Note）+ `label()`/
  `next()`（循环切换语义——与视图共享同一枚举面，e2e 无 GUI 亦可用）；
- `add_underline_from_screen`：与高亮同 QuadPoints 变换面
  （`/Underline` 标准子型），缺省色 = `UNDERLINE_COLOR`（#45 笔迹蓝
  同源——仓内既定视觉，零新而异）；
- `add_note_from_screen`：屏幕矩形两对角 `screen_to_user` → min/max
  轴对齐包络 → `Rect::new` typed 拒退化（`/Text` 标准子型；弹出
  评语文本面 v0 不建模——引擎 Note 同语义）；
- 三手势共享 `commit_draft` 出口（页界检查 + 载荷形状断言单点化）。

**视图面（`pdf_pages.rs`）**：

- `annotate_tool` 字段（缺省高亮）+ `annotate_hint` 提示横幅；
- **退化右键单击 = 循环切换工具**（高亮→下划线→便签→高亮；原
  「退化单击丢弃」语义升级为工具选择——零键位面新增，无焦点依赖）；
- `commit_annotation` 三手势派发（同一懒初始化/DPI 推导/flush/
  reload 链）；提示横幅提交成功即清零（不永久占屏）。
