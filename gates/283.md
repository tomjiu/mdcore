# #283：XLSX 消费倒挂——XlsxEditor 接产品导出路径 + 重算接线 + 结构性丢失诚实账本（2026-11-06，P2 / 审计 P1-5、P1-6、P2-12）

**背景**（审计 P1-5/P1-6，phase1 路线图 T8/X-2、X-1）：
`XlsxEditor`（xlsx_edit.rs 1,806 行高保真原位编辑器）零产品消费方
——`git grep XlsxEditor` 仅命中自身定义与测试；产品导出路径
（mdcore-wasm `xlsx_grid::export_with_edits`）独走**有损 rebuild**
（rust_xlsxwriter 全量重放：丢样式/图表/条件格式/数据验证，且不
登记）；「保真最好」与「保真最差」的路径消费完全倒挂。P1-6
（改数据格后公式 `<v>` 缓存陈旧）随 rebuild 重算面（#113）已在
rebuild 路径闭合，但原位路径无重算接线。

**实现**（分支 `feat/283-xlsx-editor-wiring`，基于 main `0152890`）：

- **引擎侧编排面**（office-io `rebuild.rs` 新增 `pub fn
  export_edited(book, bytes, edits) -> (Vec<u8>, ExportStats)`）：
  - **in-place 优先**：编辑全为 text/number/bool →
    `XlsxEditor::open(bytes)` 原位手术。**表序守卫**（editor
    workbook.xml 与 calamine 两读面不同名同序 → 拒坐标迁移，
    回退 rebuild——坐标系漂移面宁可回退不冒险）；
  - **X-1 重算接线**：源档公式在场（`formulas.start().is_some()`）
    → 复用 rebuild 的 `prepare_recalc`（编辑即落位灌入 + 全簿
    重算）→ 公式缓存表经**编辑面新增手术**回写。重算失败 →
    **降级保真直通**（源缓存保留 + skipped 登记——与 rebuild
    路径同一降级纪律，非阻断）；
  - **rebuild 兜底**：in-place v1 拒改面（empty/formula 编辑、
    公式格落格、chartsheet/容器拒绝、保存失败）→ 全量重放
    （公式文本 + 重算缓存），`fallback_reasons` 逐条可追溯；
  - **P2-12 诚实账本**：`structural_loss_notes(bytes)`——
    rebuild 路径的**结构性丢失**逐类**在场才登记**入 `skipped`
    （裸簿零噪音）：图表部件（`xl/charts/`）/ 图片与 drawing
    （`xl/media/` + `xl/drawings/`）/ 条件格式
    （`<conditionalFormatting`）/ 数据验证（`<dataValidation`）/
    单元格样式 xf（cellXfs > 1——仅默认 xf 不登记）/ 隐藏行列
    与外部链接（复用 #265 `xlsx_structural` 结构面引擎，容错
    降级）。检测面全容错：zip 缺件/坏件 → 该类跳过不阻断。
- **编辑面新手术**（xlsx_edit.rs）：
  - `pub fn set_formula_cache(sheet, cell_ref, FormulaCache)`：
    仅公式格（`<f>` 在场），`<f>` 元素/`s` 样式索引/其余属性
    **原文零接触**，单点替换/插入 `<v>` 缓存文本 + 按缓存类型
    调整 `t` 属性（Number → 移除 / Text → `t="str"` /
    Boolean → `t="b"`；`t` 已同值 → 开标签字节零接触）。无
    `<v>` 的 shared 自闭合形（`<f t="shared" si="0"/>`）→ 缓存
    插到 `<f/>` 后。与值编辑**按构造互斥**（值编辑拒公式格，
    缓存更新仅公式格——双账本同格防御拒）；
  - 手术引擎 `apply_cell_edits`/`emit_row_cells` 双账本同趟
    落账；`CellScan` 增 `content_open`（开标签域锚——手术定位
    依赖，既有扫描件补填）。
- **wasm 产品接线**（mdcore-wasm `xlsx_grid.rs`）：
  - `WasmBook` 保留**源档字节**（in-place 原料——内存代价 =
    源档一倍，与编辑功能一起在场）；
  - `export_with_edits_core(book, bytes, edits_json)` →
    `export_edited`；错误码不变（`rebuild_invalid/limit/engine`
    ——in-place 拒面全数兜底到 rebuild 同拒）；
  - 统计 JSON 双路径**六键恒在**（`path`/`sheets`/
    `cells_written`/`merges`/`hyperlinks`/`edits_applied` +
    `recalc_cells`/`skipped`/`fallback_reasons`）——web 宿主
    （xlsx_grid.ts 防御式消费 + `skipped` 长度亮警）零改动；
    `in_place` 的 `cells_written` = 手术触及格数（值编辑 + 缓存
    更新），与 rebuild 全量重放口径不同，文档在案。

**能力边界（如实登记）**：

- in-place v1 值面 = text/number/bool（empty/formula 编辑恒走
  rebuild——清格空语义与公式文本重写是 rebuild 的既有面）；
- 公式**编辑**（改公式文本）仍非本 PR 面（XlsxEditor v1 拒改
  公式格 + rebuild 的 `EditValue::Formula` 承载）；铁 calcChain
  在 in-place 路径透传（公式格零增删 → calcChain 恒准确；
  rebuild 路径引擎不写 calcChain——Excel 打开自算，既有行为）；
- mang-shell XLSX 视图只读是 **G6 定位**（#68），不在本条范围
  ——产品写路径 = wasm grid（唯一消费方，审计 06 号笔记实证）。
