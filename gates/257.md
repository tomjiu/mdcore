# #257：office-io 多节分节符读写面（2026-11-06，R6·P1 / 审计 P1-1 / 排期 #230）

**背景**：多节文档读面只取末节 sectPr——中段节页眉/页脚/几何/节边界
静默丢（`extract_headers_footers` 只读 `docx.document.section_property`，
审计 P1-1 已确认）；写面单节 `page_geometry` 不可表达多节。消费侧
（研究仓导出链）投标文件「封面无页码 + 正文页边距异构」是六表/七格式
件之后的下一个硬需求——现状绕行 docx-rs 直连加性桥（单节）+
`page_break_before`。真实语料佐证非边角形态：health-check 语料 636 件
中 **84 件多节**。

**实现**（分支 feat/257-multisection-docx，基于 main `7decc10`）：

读面：
- `DocxDocument.sections: Vec<SectionData>`（恒 ≥1 条——单节文档 = 1
  条末节）：节序/来源（Mid/Final）/几何（pgSz/pgMar → `PageGeometry`
  twips 同域——读模板→写导出零换算）/titlePg/分栏数/节类型
  （`SectionKind` 五值）/起始页码/六槽位页眉页脚/**块区间**
  `[start, end)` 连续切分 blocks 全序；
- 中段节页眉/页脚部件**引擎第二趟自解析**：docx-rs `read_docx` 只把
  内容联接到末节（`read_docx.rs:232-290` 只查 `document.
  section_property` 的引用——中段节引用在、内容永不联接，P1-1 根因）。
  引擎侧 `slot_part_path` 解析 rid → 部件路径 → zip 单趟收集部件 XML →
  `docx_rs::Header/Footer::from_xml` 解析 → 块序提取（与末节同构：
  段落/表 + numPr/ind 同路径）；槽位降级语义与末节一致（悬空 = 严格
  拒 / 兼容警告 + 跳过）；
- 几何读取：`PageMargin`（types 版）字段 pub 直读；`PageSize.w/h`
  私有无 getter——serde_json 序列化通道（同 gridSpan/verticalMerge
  合并面先例 P2-1，版本钉死 0.4.22）；
- 边界坐标系：extract_blocks 记中段节标记（段落级 sectPr 段 + 其
  DrawingML 文本框块之后）→ `apply_vml_textboxes` 插入位移**同步重映射**
  （插入点及之后边界 +1——插入的文本框块是宿主段内容，归属宿主节）；
- 末节行为**零变化**（文档级 `headers`/`footers` 语义 = 末节，
  health-check 基线零漂移口径）。

写面：
- `DocxWriter::section_break(SectionBreakSpec)`：已发射内容后闭合一节
  （几何/titlePg/起始页码/本节六槽位 `SectionSlots`）——docx-rs
  `DocumentChild::Section` 落地（zipper 已收集段落级节页眉部件
  `zipper/mod.rs:197-201`，零依赖改动）；OOXML 段落级 sectPr 语义
  （Section::build_to 发射 `<w:p><w:pPr><w:sectPr>`）；
- `DocxWriter::page_number_start(u32)`：末节起始页码（封面不计数 +
  正文从 1 起算的典型位；中段节经 spec 治理）；
- V9 几何正值域校验同判据提前到构造期（粘性 `validation_error` →
  save 漏斗 `InvalidInput` 拒，零产物）；r4-t2 计数：节断点段 +1。

编辑面：sectPr 属编辑辖外（document.xml 字节手术不动段落属性）——
`edit_preserves_sections` 回归钉住（多节文档手术编辑 → 节结构逐字段
不变）。

**测试**（`tests/docx_sections.rs` 6 锁，全部本机 Linux 实跑）：
1. `section_break_write_read_roundtrip`：封面（titlePg 无槽位）+ 正文
   （异构边距/页眉/页脚页码域/起始页码 1）双节——回环节数/来源/几何/
   槽位/块区间断言 + OOXML 直检（`<w:sectPr` ×2、段落级形态、
   titlePg、`w:start="1"`）；
2. `single_section_document_has_exactly_one_final_section`：单节基线
   （新字段不破既有形态）；
3. `corpus_docx4j_mid_section_slots_recovered`（**P1-1 钉面**）：
   docx4j `headers_footers_sections_multiple.docx` 中段节 3 页眉
   （first="Section 1 – first page"/default="Section 1 – subsequent
   page"/even）+ 3 页脚（default="Just a footer."）全量恢复——此前
   静默丢；块区间 (0,5)/(5,9)；双口径断言末节行为零变化（文档级仅
   "Section 2"）；
4. `corpus_poi_three_sections_each_with_own_header`：POI `Headers.docx`
   3 节各自 default 页眉（Section 1/2/3——前两节此前丢）；区间
   (0,2)/(2,4)/(4,5)；
5. `edit_preserves_sections`：手术编辑幸存逐字段对照；
6. `section_break_geometry_validation`：越域几何粘性拒绝。
语料门：夹具缺失 → `[SKIP]` 横幅显式可见（直接点名子目录路径，不经
