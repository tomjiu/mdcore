## 结构完整性证据链（沙箱等价 + 实机补验计划）

1. **python-docx 独立打开**：9,307 段 / 313 表，零异常（第三方消费者视角）；
2. **LibreOffice 转换渲染**：双档均成功（330/935 页）——LO 的 docx 解释器对结构非法件会拒转/崩，双档过 = 结构合法性旁证；
3. **引擎读回**：harness stats 面块计数与夹具生成器账本一致（word_count 七字段）；
4. **Word COM 实机探针**：TR-2D `word_probe.ps1` 模式已就绪（test-artifacts/TR2/），待 #28 Windows CI 窗口补验「打开不弹修复提示」终判——诚实登记：本沙箱无 Word。

## 与 R-1 的维度差异（#29 立项理由复核）

R-1 测「文件大」（50MB/117k 段导入）；N-1 测「成品长」（40 万字/3.4k 段导出）。压力面正交：导出侧 160 ms / 94 MB——**远低于导入侧**（docx-rs 模型构建 + zip inflate 双份峰值是导入瓶颈，导出为单遍流式发射）。
